FEEDBACK HELPS THE NEXT REPLY

See learning in action

Compare a real AI reply before and after a reviewed writing lesson. Both replies use the same question and approved knowledge. Nothing from this test is sent to a tenant.

2. Review the lesson

The lesson changes how the AI writes, using only approved facts. The next run retrieves it automatically from isolated feedback memory.

What we measure

Three clarity checks: start directly with two numbered points, ask exactly one question, and use no more than 90 words. The word count is shown too. These checks measure this writing task, not overall AI accuracy. The results can show improvement, no change or a lower score.

A lesson qualifies when it passes more clarity checks, or passes all three checks with a reply at least 20% shorter (and at least 12 words). When an approved lesson improves this comparison, it is automatically saved for future replies to the fictional demo tenant. It stays separate from real property facts and other tenants.

Reviewed lessons from completed cases

Public auto-reply lessons show the question they cover and the cases that matched the current approved version. A match can prepare a draft for a public source or send an answer in the complaint portal.

Where should cases go?

BeLive chooses the team for each topic. The AI identifies the topic; the saved routing decides the staff queue. Blank topics go to Support team. Saving a change applies to the next handover.
