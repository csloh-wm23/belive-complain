# Publishing this project

Production AI uses the official NousResearch Hermes `run_agent.AIAgent`, with GPT/OpenAI as its model provider. Do not bypass Hermes based on a model ID. The explicitly selected `direct` engine exists only for legacy transport tests; it must never be silently used when native Hermes is missing or fails. Verify native executor identity, version, model calls and tool executions before claiming Hermes ran. WhatsApp connection readiness is separate from native Agent readiness. Retain the phone Business app; do not unregister the number to bypass coexistence onboarding.

The user chose to keep reviewed knowledge private. The public repository contains source code and redacted instructions only. Never stage or publish knowledge/team-memory.enc.json, the knowledge/ folder, recovery keys, local databases, customer conversations, .env files, credentials, raw source PDFs or unreviewed feedback. Encryption does not grant permission to publish the knowledge package.

Before each source-code push, run python scripts/knowledge_backup.py export in the active installation to preserve a private encrypted backup. Then run python scripts/knowledge_backup.py check: the backup must match current approved knowledge and private paths must not appear in the Git index. The archive stays ignored locally and is not included in the public commit. If validation or conflict checks fail, preserve local records and stop the push. Do not claim that code publication backed up or synchronised knowledge.

To share approved SOP and lessons with an authorised teammate, transfer the encrypted archive and matching recovery key through a private channel. On the other computer, place the archive at knowledge/team-memory.enc.json, import the key in Team knowledge backup, and restore. Keep existing .env, data and private credential key files when updating code. Preserve conflicts for review and current revocations. Existing local restore support remains available; code-only pulls do not download newer knowledge.

Removing a previously tracked encrypted archive from the current tree does not remove historical copies from Git history. Do not rewrite shared history without explicit user authorisation.
